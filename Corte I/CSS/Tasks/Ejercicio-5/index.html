Explicación de las diferencias observadas

  • display: block Los elementos ocupan todo el ancho disponible y empiezan en una nueva línea. Se pueden modificar su width y height . Ejemplo: los div


  • display: inline Los elementos se colocan en la misma línea, solo ocupan el espacio de su contenido. No se les puede modificar el width ni el height. Ejemplo: los span.

  • display: inline-block Es una mezcla: los elementos se colocan en la misma línea, pero aceptan width y height. Es útil para crear botones o tarjetas alineadas horizontalmente.

  • display: none Oculta completamente el elemento. Desaparece de la pantalla y no ocupa espacio en la página.
